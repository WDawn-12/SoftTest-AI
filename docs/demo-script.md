# SoftTest-AI 演示视频执行手册

> 目标：3–4 分钟演示视频，简历投递时附 B 站/腾讯视频链接。

---

## 一、演示前准备

### 1.1 启动方式选择

| 方式 | 启动命令 | 适合场景 |
| --- | --- | --- |
| **Docker Compose（推荐）** | `docker compose up -d --build` | 体现"完整部署能力"，最接近生产 |
| 本地开发 | `.\start-dev.ps1` | MySQL 起不来时回退；后端 demo 模式同样可用 |

> 不论哪种方式，后端 `AI_PROVIDER` 默认就是 `demo` 模式，**无需配置任何 API Key**，
> AI 生成的需求解析、测试点、测试用例都会返回结构化示例数据，效果完整。

### 1.2 数据准备

- 示例需求文档：`docs/examples/示例需求_图书管理系统.md`（直接用）
- 数据库首次启动会自动执行 `docs/sql/init.sql` 初始化表结构
- 推荐提前注册一个演示账号（用户名 `demo`，密码 `Demo@2026`），并在仪表盘放一个"图书管理系统"项目骨架，演示时直接进项目

### 1.3 录屏工具

- **首选：OBS Studio**（[https://obsproject.com](https://obsproject.com)）—— 跨平台，配置简单
- 备选：Windows 自带 `Xbox Game Bar`（`Win + G`），但只支持全屏录制
- 分辨率建议 **1920×1080**，帧率 **30fps**，码率 **6000–8000 kbps**
- 录制前关掉无关通知、隐藏任务栏个人头像、整理桌面图标

## 二、演示脚本（3:40 总时长）

> 镜头一律走"鼠标 + 键盘操作 + 屏幕"，**不出声就用 OBS 自带/后期字幕**。
> 下面给出每个镜头的【动作】和【字幕/旁白文案】。

### 镜头 1 · 开场（0:00 – 0:20）

【画面】浏览器最大化，登录页

【动作】登录 `demo` 账号

【字幕】
> **SoftTest-AI · 基于 AI Agent 的软件测试辅助平台**
> FastAPI + Vue3 全栈，56 个 pytest 用例 + GitHub Actions CI
> 演示流程：上传需求 → AI 解析 → 生成测试点 → 生成测试用例 → 导出 Excel

---

### 镜头 2 · 新建项目 + 上传需求（0:20 – 0:50）

【画面】项目列表 → 新建项目 → 名称"图书管理系统" → 项目详情页

【动作】点击"上传需求"按钮 → 拖入 `示例需求_图书管理系统.md` → 列表出现新文档

【字幕】
> 上传需求文档（支持 md / txt / docx / pdf，自动提取文本）

---

### 镜头 3 · Requirement Agent 解析（0:50 – 1:20）

【画面】需求详情页 → 点击"AI 解析"

【动作】点按钮 → 等 1-2 秒 → 展示结构化结果（模块/功能点/角色/流程/风险）

【字幕】
> **Requirement Agent**：自动从需求中抽取
> 模块 · 功能点 · 角色 · 业务流程 · 风险等级

---

### 镜头 4 · TestPoint Agent 生成测试点（1:20 – 1:55）

【画面】测试点列表页

【动作】点击"AI 生成测试点" → 展示五类（正常/异常/边界/安全/兼容性）测试点列表

【字幕】
> **TestPoint Agent**：按软件测试规范的五类维度自动生成
> 正常 · 异常 · 边界 · 安全 · 兼容性
> 当前演示为 demo 模式，配置真实 API Key 后即接入 OpenAI / DeepSeek

---

### 镜头 5 · TestCase Agent + Test Data Generator（1:55 – 2:35）

【画面】测试点详情 → 选 1-2 个点 → "AI 生成测试用例"

【动作】展示生成的测试用例，重点展示**测试数据**字段（包含 12 类样本：正常/空值/边界/超长/SQL 注入/XSS/中文/英文/数字/特殊字符等）

【字幕】
> **TestCase Agent + Test Data Generator**
> 自动生成：步骤 · 测试数据（12 类场景）· 预期结果
> 测试数据按字段类型自动识别，覆盖软件测试规范全部场景

---

### 镜头 6 · Excel 导出（2:35 – 3:00）

【动作】点"导出 Excel" → 截图展示表头样式、冻结首行、列宽

【字幕】
> 一键导出 Excel：表头样式、冻结首行、列宽自动适配

---

### 镜头 7 · 智能问答（3:00 – 3:20）

【画面】AI 聊天面板

【动作】输入"请总结这个项目的主要风险点" → 等回复 → 展示 Markdown 渲染效果

【字幕】
> **AI 问答**：基于项目知识库的上下文对话，支持多轮记忆

---

### 镜头 8 · 收尾（3:20 – 3:40）

【画面】GitHub 仓库页 → README

【动作】滚到 CI 徽章、测试统计、技术栈列表

【字幕】
> GitHub: github.com/WDawn-12/SoftTest-AI

## 三、录屏操作步骤

1. 打开 OBS Studio → 来源 → 添加 **显示器采集**
2. 设置 → 输出 → 录像格式 `mkv`（录制稳定，事后转 mp4）
3. 设置 → 输出 → 录像质量 `高质量`，码率 6000
4. 按 **镜头脚本** 操作，**每个镜头之间按一次暂停**（OBS 自带 `Ctrl+F9` 暂停）
5. 全部镜头录完 → 文件 → 录像转封装为 mp4
