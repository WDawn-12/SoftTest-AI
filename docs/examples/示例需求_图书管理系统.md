# 图书管理系统需求说明书

## 1. 项目概述

本系统面向图书馆管理员与读者两类用户，提供图书信息管理、借阅/归还、图书查询与借阅统计等核心功能，目标是提升图书馆日常业务的数字化管理效率。

## 2. 用户角色

- 系统管理员：管理系统配置、维护用户账号、查看操作日志。
- 图书管理员：维护图书信息、处理读者借阅与归还、发布公告。
- 读者：查询图书、在线预约借阅、查看个人借阅记录。

## 3. 功能需求

### 3.1 用户管理

- 用户注册：读者可注册账号（用户名、密码、邮箱）。
- 用户登录：支持用户名密码登录，密码错误连续 5 次锁定账号 15 分钟。
- 权限控制：管理员可禁用/启用普通用户账号。

### 3.2 图书管理

- 图书录入：管理员新增图书（ISBN、书名、作者、分类、库存数量）。
- 图书编辑：管理员修改图书信息。
- 图书删除：管理员下架图书，已借出图书不可删除。
- 图书查询：按书名、作者、ISBN 模糊查询。

### 3.3 借阅管理

- 借阅办理：读者持有效身份借书，库存不足时提示失败。
- 归还办理：读者归还图书，逾期自动计算罚款。
- 预约借阅：图书全部借出时可预约，归还后通知读者。

### 3.4 统计报表

- 借阅排行：按图书、分类统计借阅次数。
- 逾期统计：统计逾期未还的读者与图书。

## 4. 业务流程

### 4.1 读者借书流程

1. 读者登录系统；
2. 查询目标图书并确认库存；
3. 提交借阅申请；
4. 图书管理员审核并办理出库；
5. 系统更新库存并生成借阅记录。

### 4.2 读者还书流程

1. 读者归还图书至服务台；
2. 管理员扫描图书确认归还；
3. 系统计算是否逾期并生成罚款；
4. 更新库存并关闭借阅记录。

## 5. 非功能需求

- 性能：支持 500 名用户同时在线，普通查询响应时间小于 2 秒。
- 安全：用户密码加密存储，接口鉴权，防止 SQL 注入。
- 兼容性：支持主流浏览器（Chrome、Edge、Firefox）与 1920×1080、1366×768 分辨率。
- 可用性：系统 7×24 小时运行，支持数据定期备份。
